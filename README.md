# Mom Chat Bot (Node.js + Telegraf)

Telegram-бот на **Node.js + Telegraf** в режиме **polling** (без webhook), который помогает собрать данные и выдать готовый текст поста для ручной публикации.

## Что умеет сейчас

- Команды: `/start`, `/post`, `/cancel`, `/back`, `/restart`
- Выбор темы кнопками: игрушки, книги, занятия, места, специалисты, рецепты, в дороге, мультфильмы, гайды
- FSM-анкета по шагам
- Полностью реализованы темы:
  - **книги**
  - **занятия** (включая блок «Вам понадобится» с поддержкой ссылок)
- Остальные темы пока показывают сообщение: «в разработке»
- В конце бот отдает «готовый пост» в `parse_mode=HTML`
- Бот **не публикует пост сам**, только выдает текст для копирования
- Добавляется подсказка: «при публикации добавьте фото/видео»

## 1) Локальный запуск

### Требования
- Node.js 18+ (рекомендуется)
- npm

### Шаги
1. Установите зависимости:
   ```bash
   npm install
   ```
2. Создайте `.env` на основе примера:
   ```bash
   cp .env.example .env
   ```
3. Вставьте токен бота в `.env`:
   ```env
   BOT_TOKEN=ваш_токен_от_BotFather
   ```
4. Запустите бота:
   ```bash
   npm start
   ```

Если все хорошо, в логах будет сообщение: `Bot started in polling mode`.

## 2) Деплой на Render

1. Загрузите проект в GitHub.
2. На Render нажмите **New +** → **Web Service**.
3. Подключите ваш GitHub-репозиторий.
4. В настройках сервиса укажите:
   - **Build Command:** `npm install`
   - **Start Command:** `npm start`
5. Создайте сервис.

> Для polling режима webhook не нужен.

## 3) Как добавить переменную окружения `BOT_TOKEN` в Render

1. Откройте ваш сервис на Render.
2. Перейдите в раздел **Environment**.
3. Нажмите **Add Environment Variable**.
4. Укажите:
   - **Key:** `BOT_TOKEN`
   - **Value:** токен из BotFather
5. Сохраните изменения и перезапустите сервис (если Render не сделал это автоматически).

## Примечания по контенту

- Возрастные теги поддерживаются в формате:
  - `#возраст_0_6мес`
  - `#возраст_6_9мес`
  - `#возраст_9_12мес`
  - `#возраст_1_2`
  - `#возраст_2_3`
  - `#возраст_3_4`
  - `#возраст_4_5`
  - `#возраст_5_7`
- Для темы **игрушки** хэштег `#игрушка` не используется (тема пока в разработке).
- Для темы **гайд** описание планируется как опциональное поле (тема пока в разработке).
- Для темы **специалист** возраст должен указываться внутри текста опыта (отдельный возрастной шаг не нужен; тема пока в разработке).
